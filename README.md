Project Description

This is my first UI design project, where I designed a user-friendly and visually appealing interface for an e-commerce website using Figma. The main objective of this project was to understand the importance of core UI elements such as color, typography, icons, spacing, and layout in enhancing user experience.

The design focuses on effective color selection to build trust and highlight important sections, clear typography for readability, and meaningful icons for smooth navigation. A clean and structured layout was maintained to ensure easy product browsing and a seamless shopping experience.

Through this project, I gained practical knowledge of UI principles, design consistency, and how visual elements influence user interaction in an e-commerce platform.
